Name of Project : "OAL Audio Player"

Author : DOUYERE Sam and LE CLEAC'H Louis
Date : 18/10/2026

-------------------------------------------------------------------------
You can open a song that is with a wav or ogg extension through our media player by clicking File > Open. This will add the music to the current list. You can then save the current list by clicking File > Save, and enter the name of the list. You can later open list by clicking File > Open list.

The media player in itself has multiple buttons : Play, to start the music from the beginning, Stop, that stops completely the music, and Resume/Pause which stop the music, but clicking on it once more play it from where you stopped it.
Under those buttons, you have a Volume scrollbar : if this bar is on the left end side, no noise will be played.
Finally, the current timestamp of the music as well as the total time of the current music is displayed, as well as a cursor displaying where you're at in the music. You can use this cursor to move around in the music, which will also update the current time after less than half a second.

-------------------------------------------------------------------------

To start the application, click on Release, and download the source code. Then, when you extract it, you can find the exe file in OAL-Audio-Player-Release > Debug > OAL Audio Player.exe
